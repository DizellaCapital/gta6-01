# Solmar Bay

A 2D top-down open-world crime game for the **Make GTA 6** bounty
(gta6-01). An original sun-soaked seaside city — no Rockstar names,
characters or assets. You are Rico, a driver back in town; Mara Voss has
eight jobs for you, and the SBPD has other plans.

## Play

- Walk, steal and drive cars, fly the helicopter from the helipad
- Wanted stars 1–5, SBPD dispatch, roadblocks, police helicopter
- 8 story missions, street race, garage, 3-person crew, 4 radio stations
- Save in localStorage, deterministic seeded world

Run it:

```sh
node serve.ts
```

Then open http://localhost:8080/ in a browser.

## Controls

WASD move / drive, E enter or steal a car, mouse aim + click to shoot,
1/2/3 call crew, Q change radio, F switch weapon, P pause, C save.
